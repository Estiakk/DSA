# Data Structures and Algorithms in C

Welcome to my **Data Structures and Algorithms (DSA)** repository! 🚀

This repository contains my implementations of fundamental **Data Structures** and **Algorithms** in the **C programming language**. The goal of this project is to strengthen my understanding of core computer science concepts through hands-on coding and problem-solving.

Whether you're a beginner learning DSA or someone looking for simple C implementations, this repository can serve as a useful learning resource.

---

## 📌 About

Data Structures and Algorithms are the foundation of efficient programming and software development. This repository includes implementations of commonly used data structures and searching algorithms, along with recursive programming examples.

Each program is written with simplicity and readability in mind, making it suitable for students and beginners.

---

## 🛠️ Technologies Used

* **Language:** C
* **Compiler:** GCC (or any standard C compiler)
* **IDE:** Works with Code::Blocks, Dev-C++, Visual Studio Code, CLion, or any C development environment.

---

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Estiakk/DSA.git
```

### Navigate to the Project Directory

```bash
cd DSA
```

### Compile a Program

```bash
gcc filename.c -o output
```

### Run the Program

**Windows**

```bash
output.exe
```

**Linux/macOS**

```bash
./output
```

## 📈 Time Complexity Overview

| Algorithm / Data Structure         | Average Time Complexity |
| ---------------------------------- | ----------------------- |
| Linear Search                      | O(n)                    |
| Binary Search                      | O(log n)                |
| Queue Enqueue                      | O(1)                    |
| Queue Dequeue                      | O(1)                    |
| Circular Queue Enqueue             | O(1)                    |
| Circular Queue Dequeue             | O(1)                    |
| Linked List Insertion              | O(1) / O(n)             |
| Linked List Deletion               | O(1) / O(n)             |
| Fibonacci (Recursion)              | O(n)                    |
| Sum of Natural Numbers (Recursion) | O(n)                    |
